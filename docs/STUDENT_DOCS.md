# Практична робота STUDENT_DOCS

## Тема

Розробка вебзастосунку для тренування розпізнавання слів на основі гри з анаграмами.

## Вступ

Сучасні вебтехнології дають змогу створювати інтерактивні навчальні застосунки, які працюють без складного встановлення та доступні користувачу безпосередньо у браузері. Одним із прикладів такого застосунку є гра з анаграмами, у якій користувач отримує слово з перемішаними літерами та має відновити правильний варіант.

Актуальність роботи полягає в тому, що невеликі освітні вебзастосунки можуть використовуватися для розвитку уваги, логічного мислення, словникового запасу та навичок швидкого аналізу інформації. Крім того, такий проєкт є зручним прикладом для демонстрації повного циклу розробки: побудови інтерфейсу, налаштування компонентів, документування, вибору ліцензії, опису приватності та підготовки технічної документації.

Метою роботи є розробка та документування вебзастосунку Anagram Game, який дозволяє користувачу проходити ігрові раунди з анаграмами, налаштовувати параметри гри та переглядати результат взаємодії з системою.

Для досягнення мети необхідно виконати такі завдання:

- проаналізувати предметну область навчальних браузерних ігор;
- визначити основні функціональні можливості застосунку;
- реалізувати інтерфейс гри з використанням React;
- додати налаштування складності, підказок і часу раунду;
- реалізувати GDPR-повідомлення про cookie та локальне збереження;
- підготувати технічну документацію проєкту;
- описати компоненти у Storybook;
- створити документи для супроводу проєкту.

Об'єктом дослідження є процес створення інтерактивного навчального вебзастосунку.

Предметом дослідження є методи та засоби реалізації гри з анаграмами за допомогою React, Vite, Storybook і JSDoc.

Практичне значення роботи полягає у створенні готового навчального вебзастосунку, який можна запускати локально, використовувати для демонстрації принципів компонентної розробки та розширювати в майбутньому, наприклад, шляхом додавання backend API, бази даних або системи статистики.

## Розділ 1. Опис Технологічного Стеку

Для реалізації вебзастосунку Anagram Game використано сучасний frontend-стек на основі JavaScript та React. Основною мовою програмування є JavaScript, оскільки вона є стандартною мовою для створення інтерактивних вебінтерфейсів у браузері. JavaScript забезпечує обробку подій користувача, зміну стану гри, перевірку введених відповідей та взаємодію між компонентами.

Основною бібліотекою для побудови інтерфейсу є React. React дозволяє створювати застосунок у вигляді набору незалежних компонентів, наприклад кнопок, карток літер, модальних вікон, сторінок гри та компонента згоди на використання cookie. Компонентний підхід спрощує підтримку проєкту, повторне використання елементів інтерфейсу та подальше розширення функціональності.

Для маршрутизації використовується React Router. Він забезпечує перехід між сторінками застосунку, зокрема стартовою сторінкою, сторінкою гри, сторінкою налаштувань і сторінкою профілю. Такий підхід дозволяє структурувати застосунок як набір окремих екранів без перезавантаження сторінки.

Інструментом розробки та збірки є Vite. Він забезпечує швидкий запуск локального сервера розробки, оновлення сторінки під час внесення змін і створення production-збірки. У порівнянні з класичними збирачами Vite має простішу конфігурацію та високу швидкість роботи, що зручно для навчального проєкту.

Для стилізації застосунку використовується CSS. Стилі визначають зовнішній вигляд сторінок, кнопок, ігрового поля, карток літер і GDPR-popup. У проєкті застосовано змінні CSS, градієнти, адаптивні обмеження ширини та медіазапити для коректного відображення інтерфейсу на різних розмірах екрана.

Документування компонентів виконується за допомогою Storybook. У Storybook описано базовий компонент Button та комплексний компонент CookieConsent. Для кожного компонента створено кілька варіацій, а властивості можна змінювати через Controls. Це дозволяє перевіряти компоненти окремо від основного застосунку та демонструвати їх роботу викладачу або майбутньому розробнику.

Для генерації технічної документації використано JSDoc. Цей інструмент аналізує коментарі у JavaScript-файлах і створює HTML-документацію. Згенерована документація зберігається у каталозі `docs/generated`, що дозволяє переглядати її локально без розгортання на сервері.

Для перевірки ліцензій залежностей використовується `license-checker`. Він формує звіт `LICENSE_REPORT.md`, у якому зазначено ліцензії використаних пакетів. Основною ліцензією проєкту обрано MIT, оскільки вона є простою, відкритою та дозволяє вільне використання, модифікацію і поширення програмного забезпечення.

Також у проєкті використано ESLint для перевірки якості коду. ESLint допомагає знаходити синтаксичні помилки, невикористані змінні та інші проблеми, які можуть впливати на підтримуваність застосунку. Завдяки цьому код стає більш стабільним і зрозумілим для подальшої розробки.

Обраний технологічний стек є доцільним для навчального вебпроєкту, оскільки поєднує простоту запуску, сучасний підхід до компонентної розробки, можливість автоматичної генерації документації та підтримку інструментів перевірки якості.

## Висновки

У межах роботи було підготовлено документацію для вебзастосунку Anagram Game, який реалізує навчальну гру з анаграмами. У документі визначено мету, завдання, об'єкт і предмет роботи, обґрунтовано актуальність і практичне значення проєкту.

Було описано технологічний стек, що включає React, Vite, React Router, CSS, Storybook, JSDoc, ESLint і license-checker. Обрані технології дозволяють створити зручний, підтримуваний і документований frontend-застосунок.

Практичним результатом є проєкт, який можна запускати локально, перевіряти за допомогою команд npm, демонструвати через Storybook і супроводжувати згенерованою документацією. У майбутньому застосунок можна розширити backend API, збереженням статистики, новими рівнями складності та більшою базою слів.
