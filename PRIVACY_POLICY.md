# Privacy Policy And User Instructions

Last updated: 2026-05-31

## Project Purpose

Anagram Game is a local educational browser game. It is intended for learning, practice, and demonstration as a student project.

## Data Processing

The project does not use a backend server and does not intentionally collect, sell, or transfer personal data.

The browser may store technical data locally:

- cookie or local storage consent status
- selected game settings, if the user allows preferences storage
- temporary game state while the app is open

## GDPR Consent Categories

Necessary storage is required for the app to work and cannot be disabled through the popup.

Preferences storage is optional and may be used to remember game settings in the current browser.

Analytics storage is disabled by default. The current app does not send analytics data to third-party services.

Marketing storage is disabled by default. The current app does not use marketing cookies or advertising trackers.

## User Rights

Because the app stores data locally, the user can remove stored information by clearing site data in the browser settings.

If the project is later deployed with a backend or analytics service, this policy must be updated before release.

## Limitations

The software is provided for educational use. It does not guarantee uninterrupted operation, data preservation, or fitness for commercial use.
