# Local Documentation Video

The project contains local generated documentation in `docs/generated`.

A recorded documentation demo video is included in the repository root.

For future submissions, record a short screen video if the documentation is not published on a public server.

Recommended recording flow:

1. Run `npm install`.
2. Run `npm run docs`.
3. Open `docs/generated/index.html` in a browser.
4. Show the generated project documentation pages.
5. Run `npm run storybook`.
6. Open `http://localhost:6006` and show the `Button` and `CookieConsent` stories with controls.
7. Save the recording as `docs/documentation-demo.mp4` or include it in the repository root.
8. Commit the video file or upload it with the repository submission, depending on the teacher's file-size rules.

Suggested video length: 1-3 minutes.
